    What a real version needs

    This page is a front end and a script. Four pieces turn it into a product.

    Messaging backend
    Rooms, delivery, read state and history, over WebSockets with a database behind them.
    Accounts and permissions
    Sign-in, workspaces and rules for who can see which channel.
    The assistant
    Calls to a language model with the channel's messages as context. Real summaries, replies, rewrites and translations replace the scripted ones here.
    Privacy controls
    A per-channel switch for assistant access, plus a record of which messages the assistant read.

    How accounts are saved
    1. Sign up sends your name, email, mobile number and password to the server over HTTPS.
    2. The server saves the account in its database. The password is kept only as a salted hash.
    3. Log in checks your password against the hash and starts a session in a secure cookie.
    4. Log out deletes the session. The account stays, so you can log back in whenever you like.
